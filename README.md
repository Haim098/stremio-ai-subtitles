# Stremio AI Subtitles Add-on 🎬✨

> AI-powered subtitles for Stremio, generated by **Gemini 3 Flash Preview**

## Features

- 🤖 **AI-Generated Subtitles** - Contextual subtitles created by Google Gemini AI
- 🌐 **7 Languages** - Hebrew, English, Arabic, Russian, French, Spanish, German
- ⚡ **Smart Caching** - Generated subtitles are cached to avoid redundant API calls
- 🎯 **Auto-Detection** - Extracts title from filename for better subtitle quality
- 📺 **Movies & Series** - Supports both movies and TV series (with season/episode context)
- ⬆️ **Manual Upload** - Already have a Hebrew `.srt`? Upload it from the web UI for any title and it appears in the Stremio player alongside AI translations (no AI step)

## Installation

### Install in Stremio

1. Open Stremio
2. Go to **Add-ons** (puzzle icon)
3. Click **Community Add-ons**
4. In the search bar at the top, paste the add-on URL:
   ```
   https://your-deployment-url/manifest.json
   ```
5. Click **Install**

### Run Locally

```bash
# Clone and install
cd stremio-ai-subtitles
npm install

# Start the server
npm start

# Install in Stremio using localhost URL:
# http://localhost:7000/manifest.json
```

## Translate with your own Claude key (Anthropic)

Open the ⚙️ settings in the web UI, paste an Anthropic API key (`sk-ant-...`) and
press **בדוק ושמור**. The key is checked against Anthropic and the dropdown is
filled live from the Models API with the Claude models your key can use, so new
models show up without a code change. The newest model of each line is listed
first, older ones below, deprecated ones last (retired ones are hidden). Haiku is
cheapest and fastest, Opus is the highest quality. If the model list can't be
loaded (Anthropic outage), a built-in list of the current models is shown instead
(`FALLBACK_MODELS` in `anthropic.js`). From then on every translation runs on Claude with
that model and is billed to your Anthropic account.

The key and model stay in your browser (localStorage); they're sent with each
translation request and never stored on the server. Press **הסר** to go back to
the default engine.

## How It Works

1. 📺 When you play content in Stremio, the app requests subtitles from all installed subtitle add-ons
2. 🔍 This add-on receives the content ID, type, and filename
3. 🤖 It sends the title to Gemini 3 Flash Preview with a prompt to generate SRT subtitles
4. 📝 Gemini generates contextual dialogue and scene descriptions in the requested language
5. 💾 The SRT file is cached for future requests
6. ✅ Stremio displays the AI-generated subtitles as an option

### Manual Upload

In the web UI, search for a title and open the source picker. Besides the download
sources you'll see **⬆️ העלה קובץ משלך** — pick a Hebrew `.srt` file from your
device and it's validated, stored under the `upload` source, and served by the
add-on in the player just like a generated translation. Re-uploading replaces the
manual track for that title. SRT only (max 5 MB); VTT and other formats are rejected.

## 🚨 Important Note

These subtitles are **AI-generated content** based on the title of the media. They are NOT real transcriptions of the audio. They provide contextual, creative subtitles that relate to the content topic.

## Deployment (Render.com - Free)

1. Push to GitHub
2. Connect to [Render.com](https://render.com)
3. Create a new **Web Service**
4. Set Build Command: `npm install`
5. Set Start Command: `npm start`
6. Add environment variable: `GEMINI_API_KEY`
7. Deploy!
